# PrimeSUD

A text-based single-user RPG for the HP Prime graphing calculator, inspired by MUDs (Multi-User Dungeons).

## Requirements

- HP Prime graphing calculator or the HP Prime Virtual Calculator emulator
- HP Connectivity Kit for transferring files to a physical device

## Physical hardware bugs

- If things seem to work well on the emulator but you experience weird glitches or data corruption on the physical Prime, try resetting first (e.g. Esc + Apps + On, FCO, etc.)

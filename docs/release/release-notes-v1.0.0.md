# PrimeSUD 1.0.0

First stable release of PrimeSUD, a single-player MUD-like RPG for the HP Prime graphing calculator.

Based on ROM 2.4, with enhancements ported from 1stMud, PrimeSUD brings dungeon-crawling gameplay to the calculator's 320x240 screen.

Version 1.0 establishes PrimeSUD's stable baseline for broad content parity with 1stMud 4.5.3, within its documented single-player adaptations and HP Prime constraints. Future releases may move beyond that baseline with new content, balance changes, and further calculator-specific refinements.

## Highlights

- Classes, races, remorting, multiclassing, spells, skills, and combat stances.
- Quests, global quests, trivia points, shops, homes, and an economy.
- 50 bundled areas with lazy loading and bounded memory use.
- Automapping, exploration tracking, and area pathfinding.
- Keypad macros, command history, scrollback, autosave, and save backups.
- Extensive solo adaptations of traditionally multiplayer systems.
- PC runners for desktop play and testing.
- Support for both G1 and G2 HP Primes.

## Installation

Download `PrimeSUD-v1.0.0-hpprime.zip` and transfer it using the HP Connectivity Kit. The archive contains the complete `primesud.hpappdir` folder.

PrimeSUD requests a 6 MB app heap. If the calculator reports insufficient memory, power-cycle it before attempting a soft reset; see the README for details.
